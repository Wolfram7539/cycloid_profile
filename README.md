# Cycloid Drive DXF Generator (サイクロイド減速機ジェネレーター)

Inventorなどの3DCADで読み込める、サイクロイド減速機の正確な歯形（ディスク外形・出力ピン穴・中心軸穴）をパラメトリックに生成し、DXF形式で出力するGUIツールです。

## 特徴 (Features)
* **リアルタイムプレビュー**: パラメータ（減速比、偏心量、ピン配置など）を変更すると、即座にMatplotlibのグラフに形状が反映されます。
* **正確な歯形計算**: ピンの中心が描くエピトロコイド軌跡から、法線ベクトルを用いてピンの半径分を正確にオフセットしています。これにより、干渉のない滑らかなサイクロイド曲面を生成します。
* **CAD親和性の高いDXF出力**: Autodesk Inventorなどでエラーなく読み込めるよう、R12互換の軽量な `POLYLINE` 形式のDXFを出力します。

## 必要要件 (Prerequisites)
* Python 3.x
* [uv](https://github.com/astral-sh/uv) (高速なPythonパッケージマネージャー)

## インストールと起動 (Installation & Usage)

このプロジェクトは `uv` を使用して管理されています。

```bash
# 1. リポジトリのクローン
git clone https://github.com/Wolfram7539/cycloid_profile.git
cd cycloid_profile

# 2. 依存関係のインストールと環境構築
uv sync

# 3. アプリケーションの起動
uv run cycloid-profile
```
## 操作手順
1. アプリケーションを起動すると、左側にパラメータ入力パネル、右側にプレビューが表示されます。

2. 左側のパネルで、設計したい減速機の各種パラメータを入力します。

3. 値を変更するか Enter キーを押すと、右側のプレビューが更新されます。

    * 青: サイクロイドディスク外形

    * 赤線: 出力ピンを通す穴

    * グレー破線: 外輪ピン（ステーター）

4. 形状に問題がなければ、[DXFとして保存...] ボタンを押してファイルを書き出します。

## CAD（Autodesk Inventor）での読み込み手順
1. Inventorで新規パーツ（.ipt）を作成し、任意の平面で2Dスケッチを開始します。

2. リボンの [スケッチ] タブ ＞ [挿入] パネルにある [ACAD] ボタンをクリックし、出力したDXFファイルを選択します。

3. インポートウィザードで以下の設定を確認して [完了] を押します。

4. インポート先の単位を 「ミリメートル (mm)」 にする。

5. フリーズを避けるため、「端点を拘束」のチェックを外す。

6. インポートされたスケッチを終了し、[押し出し] ツールで青線の内側（穴以外の部分）をクリックして立体化します。
